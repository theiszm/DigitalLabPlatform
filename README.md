# Digital Lab Platform

A web-based simulation of a laboratory data system.

## Features
- Instrument simulation (background service)
- Data ingestion API
- SQLite database
- Basic dashboard

## Tech Stack
- C# / .NET
- ASP.NET Core MVC
- Entity Framework Core
- SQLite

## API Example
GET /api/readings?instrumentId=1

## Purpose
Inspired by scientific data platforms (e.g. lab systems, etc.).
